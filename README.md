# Anjali Raksha Bandhan Website

A lightweight 7-page surprise website made for GitHub Pages.

## Files
- `index.html` + `page2.html` … `page7.html`
- `style.css`, `script.js`
- `assets/` with 6 photos and 3 optimized MP4 videos

## Video optimization
The edited videos are H.264 MP4 with `faststart` enabled for progressive web playback. They remain 1080×810 and use CRF 21, with AAC audio at 96 kbps. This keeps quality high while reducing file size and improving initial playback compared with the originals.

## GitHub Pages
Upload the whole project, including the `assets` folder, to the repository root. Pages should publish from `main` / root.
